# Model assets

- `yolo11s.pt`: existing Ultralytics vehicle detector weights.
- `accident_ncnn_model/`: inherited accident detector export, including metadata and NCNN parameters/weights.
- `yolo11s.engine`: optional machine-specific TensorRT export (ignored).

These files were moved without changing their contents. Model terms and provenance are separate from the source-code MIT license. No training accuracy claim is made for the inherited accident model.
